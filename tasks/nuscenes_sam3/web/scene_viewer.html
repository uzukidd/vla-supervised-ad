多边形地图；空白表示未知区域。 / Polygon map; blank = unknown.

Oriented 3D boxes enclose retained support; surface classes are excluded. New exports merge same-class camera instances within a frame when they share ≥3 LiDAR points and ≥30% of the smaller support. Unmatched boxes may repeat; these boxes are not tracks. 中文：三维旋转框包围保留点，surface 类不生成；新导出中同帧同类跨相机实例共享至少3点且占较小实例至少30%时合并。未匹配实例仍可能重复，跨帧不跟踪。

Class 0 points use neutral gray voxels; independent of semantic class filters. 中文：语义为0的点生成灰色体素，独立于语义类别筛选，包含清洗后未分配的点。

Semantic voxels use the most frequent retained point class and its saved color. Unassigned points are excluded; class toggles hide winning classes. 中文：语义体素取保留点中数量最多的类别并按类别配色，未分配点不参与；类别开关控制对应体素显示。
