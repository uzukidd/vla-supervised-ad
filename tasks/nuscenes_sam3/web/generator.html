平面生成参数 / Plane generation

Planes interpolate labeled LiDAR support; height follows each class's measured median. 中文：由染色 LiDAR 支持点插值生成平面，高度取各类别实测中位数。

Smaller: finer grid, more memory. 中文：越小越细，内存开销越大。

Centered on LiDAR; 100 means ±50 m. 中文：以 LiDAR 为中心，100 表示前后左右各 50 m。

Smaller: fewer gaps bridged. Larger: more fill. 中文：调小减少跨空洞连接；调大增加填充范围。

Controls scene-map output sampling. 中文：控制场景融合地图的栅格，不改变源平面插值。

零水平面栅格投影 / Z=0 grid projection

Split global Z=0 into BEV cells, sample each cell in camera masks, then vote on ground classes. 中文：在全局 Z=0 划分 BEV 栅格，对每格内部采样点读取六路相机语义像素，按票数聚合已勾选的平面类别；未覆盖区域留空。复用上方栅格分辨率和范围。

3 means 3×3 samples per cell and camera; duplicate pixels count once. 中文：3 表示每格每相机采样 3×3 个点，重复像素只计一次。

高级参数 / Advanced
3D 占据网格 / 3D occupancy grid

Only retained semantic points form XYZ voxels; the most frequent class supplies each voxel's color. Unassigned points are excluded. 中文：仅使用清洗后仍有语义类别的点生成 XYZ 体素，按点数最多的类别染色；未分配点不参与。数值越小越细、开销越大。
